Oasis: My Digital Garden
![alt](/Users/nai/Developer/Oasis/public/image/Miku.jpg)
这是一座属于我们的数字避难所。

在喧嚣的网络世界中，我希望能保留一寸自己的净土。这里没有算法推荐的流量焦虑，没有即时通讯的紧迫感，只有思考、音乐，以及随时间静静流淌的文字。

🌿 关于花园 (The Philosophy)
Oasis 不仅仅是一个博客，它是一场关于“数字秩序”的实验。我在这里沉淀关于 Web 开发的思考、大模型落地的探索，以及那些不愿被社交媒体转瞬即逝的信息流所吞没的感悟。

在这里，你可以看到：

Curated Thoughts (博客区)：关于全栈架构、技术方案与心流体验的沉淀。

Resonance (音乐共鸣)：我每天都会选定一首曲子作为当下的情绪锚点，希望它能成为你访问时的陪伴。

Fallen Leaves (落叶共鸣)：我不喜欢吵闹的社交评论区。当你读到某一章文字时，可以在底部轻轻留下一片“落叶”，这是我们跨越空间的共鸣。

🛠️ 核心架构 (The Architecture)
这个花园建立在现代 Web 技术栈之上，追求极致的性能与体验：

Frontend: React + Vite + Framer Motion (保证了阅读舱丝滑的弹窗感与细腻的物理反馈)。

Backend & Auth: Supabase (轻量级的云端大脑，负责鉴权与数据存储)。

Styling: Tailwind CSS (配合深度的昼夜模式与极简排版)。

Data Flow: 基于乐观更新 (Optimistic UI) 的交互模式，让每一次互动（如留言回复）都能实现 0 毫秒的视觉延迟。

🌗 交互体验细节
昼夜节律 (Day & Night)：点击左上角的隐秘开关，花园会随着光影切换，从白日的温润纸张切换到深邃的暗黑模式，守护你的双眼。

沉浸式阅读：点击任何文章，页面会平滑地演变为一张悬浮的“实体纸张”，隔绝掉所有的视觉噪点，让你能专注地阅读。

数字档案 (Digital ID)：点击侧边栏的头像，可以唤出我的名片。这是我作为一个全栈开发者，在这个数字世界的身份标签。
