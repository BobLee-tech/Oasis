# 星图 v5.1 · 保留质感的精修

2026-09-26 起草，2026-09-28 完成这轮检查。依据用户反馈修订：v5 的扁平示意过于简陋，原型的材质和氛围更好。本文件替代 v5 的视觉方向与删减清单；原型 v4.1 重新作为视觉基准。

## 判断修正

上一版把两件事混在了一起：降低功能理解成本，和降低视觉细节密度。前者有必要，后者削弱了 Oasis 的辨识度。

原型的质感来自多个细节共同作用：石头的不规则轮廓与三段光照、留在地面的柔影、石面的苔与皴笔、砂纹遇石绕行、暖光照在纸面、玻璃边缘透光、夜里不同尺度的星核与光晕。去掉这些之后，即使节点和连线整齐，也只剩下一张普通关系图。

再版原则调整为：**保留丰富的静态细节，整理信息层级，控制同时运动的元素。**

## 必须保留的视觉骨架

| 原有元素 | 新决定 | 可以精修的部分 |
|---|---|---|
| 不规则庭石、五档尺寸、三段渐变、地面影子 | 保留 | 微调尺寸与明暗，让小石更可见；不改成圆点或扁平胶囊 |
| 常青石的苔、种子石的空心轮廓 | 保留 | 不再叠加大量额外状态环；文字依然说明状态 |
| 三层绕石砂纹、远处渐隐的直纹 | 保留 | 控制密集区交叠；移动端减掉远处细纹，不删主轮廓 |
| 玻璃面板、内侧高光、柔和投影 | 保留 | 面板更好读，减少纹理透入正文；不替换成整块平涂色 |
| 飞石小径、入口灯笼、桥 | 保留 | 默认弱显示，当前关系变清晰；灯笼仍提供阅读起点 |
| 竖排庭名与少量侧排英文 | 保留 | 尊重碰撞避让；长名称与手机横排 |
| 星核、分类光晕、常青星芒 | 保留 | 普通星保持稳定，少数亮星缓慢明暗变化 |
| 池面天空、月相 | 保留为气氛层 | 不伪称实时天象；与数据星保持明显强弱差异 |
| 绿／粉涟漪、石的轻抬起、昼夜换光 | 保留 | 第二圈更淡，连续交互可打断；不让所有节点同时呼吸 |
| 时光回放 | 保留可体验版本 | 放在次级入口，后续只简化操作与退出逻辑，不急于删除 |

五档大小暂不改成三档。它们既是内容编码，也构成石群的节奏；是否合并应看真实尺度下的辨认结果，而不是为简化规格先牺牲形态。

## 本轮原型实际改了什么

新副本：`sandprototype-v5.1.html`。原始 `sandprototype.html` 不动。

1. **沿用原来的完整场景绘制。** 继续使用原石形、苔、砂场、飞石、灯笼、星晕、月相及天空数据，保留所有文章空间位置。
2. **温暖纸白和原夜墨为主。** 略调文字到灰绿，改善层级；不采用上一版整页青墨面板的扁平外观。
3. **玻璃更有层次。** 保留半透明、模糊、细边与投影，补一层很淡的内高光；复用仓库已有 `noise-128.png` 作为低强度桌面颗粒，不新增网络素材。
4. **标题回到画面中心。** 新增中文“砂与星”主标题，英文 eyebrow 与诗句各退一级，不再只靠极小的英文标记定义页面。
5. **目录更好读。** 304px 宽，正文行 14px，元信息适度放大；话题与图例收进原位置的折叠区，主要内容量大的分类优先，统计缩成一行。
6. **详情优先给阅读入口。** 标题 25px，摘要采用正体；阅读按钮移到摘要之后，不被关系列表推到屏幕外。去掉访客卡片中的 Markdown 写作教学。
7. **面板按宽度让位。** 768–1399px 时详情在左栏原位出现；≥1400px 时保留目录与右侧详情并列的探索体验。隐藏的面板退出键盘交互。
8. **保留流动感，减少集体闪烁。** 只有五等星保留自动微闪；新近照料的环在照料模式或选中状态显示；粒子由 26 减为 12，并在后台／窄屏停止持续绘制。
9. **评审控件与正常画面分开。** `?review=1` 才显示规模、慢放、样张及待照料演示入口。时光、小径和主题仍可体验。
10. **修正原型可复现性。** 字体路径适配当前 docs 位置，月相标成固定日期示意；未声称星空已实现实时天文校准。
11. **解决浮层冲突。** 时光拨盘打开后工具条收起，关闭后恢复焦点；同栏的目录与卡片错开显隐，避免透明面板切换时两层文字叠在一起。

## 下一轮仍应优化，但不靠删材质解决

### 版式

稀疏 8 篇时，不靠扩大空白制造“高级感”。应继续研究三片庭的尺度、距离与画面重心，让石群既像自然落座，也能在第一眼看清。60 / 160 篇时，重点处理标签冲突和砂纹叠加，不机械增大每个节点。

标题可以增加气质，但不能抢过石群。正文可读性主要在目录与卡片提升；地图注记维持精细尺度，以免字比石更像主体。

### 动效

保留“石轻落、砂纹显现、星逐渐亮起”的编排。缩短重复进入、切换文章和关闭卡片的等待，而不是取消所有氛围动画。直接操作必须立即响应；景物可以在背后慢一点完成。

避免同时出现大面积闪烁、新近照料环、选中涟漪、相机飞行和卡片逐行入场。一个操作只突出一个主要变化，其余变化收敛到陪衬。

### 功能

继续保留分类、合集、搜索、引用、话题与时间探索。首屏只露出当前需要的操作，低频内容有清楚入口。以“少打扰”代替“全删除”。园丁功能与访客阅读仍应区分。

## 验证范围

本轮是基于原型副本的视觉精修，不是生产迁移。继承的数据为原型快照及模拟样本，阅读按钮仍演示跳转意图；不把它当作线上文章已经接通。

已查看 1280×720 的昼间 8 篇、文章选中态及夜间 160 篇状态；验证了时光拨盘开合、工具条显隐、关闭后焦点恢复，以及隐藏目录退出键盘交互。底部抽屉、真实手机、跨宽度切换及完整键盘体验仍属于后续验证范围。现有五档图例与样张也应在正式落地时更新其旧数值说明。

## 后续方案的衡量标准

把初版和再版并排，第一眼应该认得这是同一座庭院；再看才发现字更清楚、空间更合理、动作更从容。若为了“简洁”让材质、光感和空间诗意消失，就说明优化方向又偏了。
