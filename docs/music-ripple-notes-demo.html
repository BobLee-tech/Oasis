水下的内页

内页不该是一张浮在碟箱上的卡片。它一直在水下：唱片是投进水里的石子，涟漪荡开，你才看见它；再点一次，水纹倒放、向贴纸汇拢，内页沉回唱片里。纯器乐那一页也照这个隐喻重做：没有词的歌，就让水面替它“写字”。

现状Diagnosis

  1. 内页和唱片没有关系。它是右栏中间的一张通用模态卡（LinerNotes.tsx 的 max-w-[460px] 圆角卡 + 60% 遮罩），换成任何网站的弹窗都成立，和“唱片纸套背面”的隐喻断开了。
  2. 入口藏得深，而且只在选碟模式有。唯一入口是艺人行末 9px 的「内页 ›」；桌面切到歌词模式后 TrackCaption 不渲染，就没有入口了。
  3. 两层信息在抢眼睛。遮罩只压到 60%，下面的碟箱列表、分类栏仍清晰可读，卡片的排版因此显得单薄。
  4. 纯器乐的水纹和音乐无关。.instrumental-orbit 是两圈伪元素以 4.8s 恒定循环外扩，不论曲子是钢琴独奏还是全编制、是否暂停，都在同样地呼吸；只有线条没有光，看不出“水”。

隐喻与入口

  • 贴纸 = 内页，盘面声槽仍是播放/暂停（悬停分别显示虚线圈+「内页」与播放图标）。这解决了“点唱片”已被播放占用的冲突，且歌词模式也有入口了。
  • 大标题 = 内页：标题现在不可点，零冲突；涟漪从标题中心起。
  • 收回永远向开启时的原点汇拢，最后在原点“咚”地溅一小圈——空间记忆：内页从哪里来，就回哪里去。
  • 唱机、走带、歌词/选碟切换条浮在水面之上，不被盖住（规矩 2：控件不迁移）。点切换条会顺手合上内页。

为什么它看起来像水

  • 是波列，不是一条线：峰—谷—峰，包络居中在波前后方约 0.6λ；单根描边圈看起来只像“扩散的环”。
  • 毛细波跑在前面：水滴激起的短波（毛细波，λ<1.7cm）相速更快，所以真实水面上细碎的小纹总在主波外圈；演示里波前外有一组 0.32λ 的浅细纹。
  • 振幅随 1/√r 衰减：二维扩散的能量守恒；收回时是会聚波，振幅反而略增，到原点溅起。
  • 光从左上来：迎光坡亮、背光坡暗（与全站的光源方向一致），人眼靠这一明一暗读出“起伏”，比任何描边都可信。

内页的版面

  • 竖排标题（Shippori Mincho）贴着唱机右缘，像纸套书脊；下面一枚情绪色小印。点它就是合上。
  • 字段沿用 A6 的顺序与“缺则不显示”，但不再挤在 460px 卡里：一整栏 420px，正文 14/2.0，首字下沉染情绪色。
  • 情绪不再只是文字：情绪水纹小印，每一圈是一维 feels，粗细 = 强度 0–3，复用 mood-core.mjs 的数据。
  • 背景是整块纸套：情绪色从唱机一侧晕开 + 程序生成的纸纹，右下角大号曲号做水印。

渲染管线

  • 高度场：160×160 网格，经典的两缓冲波动方程（Hugo Elias 的 2D Water）。每步 next = (左+右+上+下)/2 − prev，乘阻尼 0.989，边缘 12 格海绵层吸收反射。CPU 单步约 0.1ms，固定 60Hz 步进。
  • 着色：一张 R16F 纹理上传高度，一个全屏三角形。法线由相邻高度差得出 → 折射偏移采样“水底”纹理（曲名、底石，Canvas 2D 预绘一次）→ 左上光的漫反射与高光 → 拉普拉斯为负处（凸面聚光）加情绪色焦散。
  • 边缘：圆形羽化 alpha，水池没有框，直接长在页面里。

性能与降级

  • 只有一个 draw call；不在视口、视图离场（useIsPresent）或标签页隐藏时停 ticker。
  • 手机：网格 96×96、DPR 封顶 1.5，细雨减半。
  • 无 WebGL2 / 氛围关 / 减弱动态：退回现在的 CSS 样式（保留），水面不动。
  • 涟漪揭页的叠加层也是一个全屏三角形、5 次解析求值，只在动画那 1 秒画，结束即清空。
