卡的器物

现网每张文章卡都是同一个模子：一条纸、一个徽章、标题、摘要。这一稿让卡从文章自己的样子长出来——有横图就裱成镜心，竖图挂成立轴，短诗写上八行笺，有一条好公式就刻成拓片，合集第一回是一册书的书衣、最新一回带出整部目录，中间几回贴一条书脊。没有图的随笔，从粉墙上的漏窗借一幅当令的节气画。下面是线上那十一篇真文章换上之后的样子；点「现网」对照，点「注记」看每张为什么是这一型。

卡型由规则推出，不随机；同月相邻两张不撞型
Specimens

八种器物 · 何时出现

规则自上而下取第一条命中的；若与同月前一张同型，就落到下一条。全是从文章已有的数据推出来的（合集、首图尺寸、正文长短、第一个代码块），不必给每篇手选。

节气画 · 十二幅

神坂雪佳《百々世草》（1909–10，克利夫兰美术馆 CC0）。琳派的大块平涂，和初音绿、樱粉放在一起不打架。一个月两个节气共一幅：没图的随笔、诗笺的笺底都按文章的日期取。点一幅，右边那张示例卡就换上它；窗形也可以换。

示例文章是虚构的一篇无图随笔。真上线时窗形不让人选：按 id 取，同一篇永远是同一扇窗。夜里粉墙沉下去、画暗两成，窗框留一道砖色的边。

落进 src 的次序

  1. 规则做成纯函数 garden/cardForm.ts：cardFormOf(post, monthNeighbors, seriesIndex)，配测试守住「同一篇永远同一型」「同月相邻不撞型」。卡片骨架（徽章、标签、续读进度、草稿虚线框、整卡可点的 a::after）不动，只换封面这一格。
  2. 首图尺寸要先知道，不然立轴 / 镜心会在图到了之后才定，版面会跳。最省事是发布时把首图宽高写进正文的图片地址（#w=1344&h=2304）或 garden_posts 加一列；退路是本机缓存量过的尺寸，第一次按镜心画。
  3. 素材进 public/garden/（约 1.2 MB，只在卡进视口时才取，节气画按需一幅一幅来），出处写进 CREDITS.md；首图卡片用 srcset 取 800 宽，别把 1600 的原图塞进一张卡。
  4. 夜里与现网的烛光接上：镜心 / 漏窗的画在夜里暗两成，悬停的烛光（.oasis-post-card::after）照旧铺在整张卡上；拓片本来就是暗的，不加烛。
  5. 手机：立轴在窄屏仍并排（轴宽 40%），诗笺只露得下的几行；其余照常单列。
