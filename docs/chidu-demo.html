名帖

登门拜访↗

灯火 · 尺牍

友链这一页的屋里，换成书斋四版的尺牍：一位邻居一封信。外壳（⌘K、昼夜胶囊、Dock、Miku）照现网不动——这一处像工坊的册页、园图的引首纸一样，有自己的「地」。

比四版多了什么

  1. 实物：信封由 three.js 画。封舌真的翻过去、露出里子，翻到底会轻轻弹一下；骑缝钤一方印，拆开时一分为二；八行笺对折装在封里，抽出来像册页一样摊开，折痕留着。
  2. 花笺：每位邻居的 aura 色成了笺色（薛涛笺的意思）；笺上淡印一枝花鸟，取自明天启五年（1625）的彩色木刻《花鸟》，又压成拱花（法线），斜光下才看得出起伏，夜里烛光最明显。
  3. 洒金红签：红签上的金点粗糙度低，烛光下有一点反光。信封纸是带帘纹的手工纸（法线），横着一道道。
  4. 光：昼是窗下，雪窗《风竹图》的竹影投在桌上、随风轻摇；夜是秉烛，烛跟着指针走，读信时挪到信边。信抬起来，影子跟着离开。
  5. 落款有来由：信末署结邻那天的干支与节气——Evan Lin 丙午寒露、hejiac 丙午霜降，日子取自 git 记录。
  6. 虚席以待：「Waiting for you」那条占位，改成一只没封口的空信封；抽出来是回帖，下面一行名帖可复制，旁边是「来信」。

怎么用

  • 移近＝拆封窥信；点击＝抽出展读；⌘ / Ctrl 点击＝直接登门（就是普通链接）。
  • Esc 或点空白＝收回；← → 换一封。
  • 右上「信上的字」：行书（默认）／楷书／仿宋，中西文一起换，当场重画所有信，方便对照。
  • 触屏：点一下拆封，再点一下读信。键盘：Tab 到信封即拆封，回车读信。

落地（若采用）

  • 引擎 lights/letterScene.ts 全程不进 React，同 sandScene / scrollScene；three 与园图共用一个懒加载包，首屏不变。
  • FriendLink 加 since（结邻日）与可选 note（园主朱批，一列小字）；color 照旧，改作笺色。
  • 建不起 WebGL：退回 DOM 信封；reduced-motion：不演进场、竹影不摇、烛不闪。
  • 手机两列；邻居多到一屏放不下时，桌面纵向可滚（相机跟着平移）。
  • Miku 的两句灯笼台词（mikuRules.ts 的 view.lights）要跟着改成信。
  • 素材约 0.6 MB（三块木刻、三张纸纹），可与园图一起上 R2。

待你定

  1. 点信先读再登门，多了一步。留 ⌘ 直达够不够？还是窥信时红签本身就可直达？
  2. 页名仍叫「灯火」：夜里秉烛读信说得通，昼里是窗下。要不要趁树测试一起想名字？
  3. 朱批 note 要不要：每封信给你留一列自己的话，没写就不显示。
  4. 信上的字定哪一手：行书最像真信，楷书更稳，仿宋最好认。
