歌词近景

“歌词 / 选碟”在代码注释里本来就是“同一舞台的两种观看距离”，但现在两种模式的版面几乎一样：唱机始终占着半个舞台。提案让镜头真的推近——唱片退到舞台边缘成为背景，歌词站到中央；沿用词场里已有的“水线”，把它变成整页的地平线：将唱的句子在水下，唱到时浮出水面，间奏时水线起伏、渐渐平静，平静了，下一句就来了。

改了什么Changes

现在提案为什么
歌词模式下唱机仍占左半舞台，唱臂、基座、转速灯都在唱片放大 1.4 倍、退到舞台左缘只露一半，基座和唱臂淡出；歌词栏从 500px 加宽到 660px听歌时歌词是主角。唱片仍在转、贴纸仍可点（内页入口），只是退成背景
注音、日/日中/中、来源三样挤在右上角，7–8px 字收进一个 Aa 按钮，弹出设置；按钮上直接写当前状态（“日中 · 注音”）。最小字号 10px设置是偶尔用的，状态却要一眼看到
间奏是一个浮在词场 42% 处的圆圈，和当前句同高，拖进度时会压在字上间奏不再是独立元素：水线本身起伏，振幅随剩余时间衰减，水线右端写“还有 6″”。下一句在水下等着结构上杜绝重叠；“水面渐平 = 快到了”比读一个弧更直觉
标题块在词场里，随歌词一起滚走标题固定在栏头（点它翻开内页），词场只放歌词滚到中段时也知道在听什么；与内页提案的入口一致
焦点在 42%，上下都是同样的淡化焦点在 50%，线上清晰、线下是“水里”：轻微模糊 + 情绪色水色。句子被唱到时穿过水线浮上来；换句时水线上从句首荡出一道小波把已有的水线、焦点光统一成一个空间隐喻；模糊来自一层静止的 backdrop-filter，歌词本身仍只动 transform

与四条规矩

  • 控件不迁移：走带、音量、歌词/选碟切换条在两种距离下位置完全不变；动的只有唱片（内容）和右栏宽度。
  • 一个元素一套动画：唱片推拉只用 CSS transition（transform 700ms，move 档位的曲线）；词场仍由 ticker 写 translateY；水线由 ticker 写 path。
  • 最后一帧等于静止态：推拉是两个静止版式之间的 transform 插值，中途切回会从当前值折返。
  • 100ms 反馈：切换条高亮当帧变，镜头跟上。

性能

  • 水下那层是一块静止的 backdrop-filter（1.1px），歌词滚过时浏览器只重算这一块；手机端去掉模糊、只留水色。
  • 水线是一条 ~110 个点的 SVG path，只在间奏和换句后 0.9 秒内每帧重写，其余时间是直线不重绘。
  • 唱片放大用 transform，不改布局；沿用现有唱盘 ticker 的旋转。

没有改的

  • 逐拍点亮（--p / --a / --b）、译文渐起、对唱/和声的左右对齐、拖拽惯性与“回到此刻”，全部照旧。
  • 选碟模式的大唱机与碟箱不动。

手机顶部Mobile header

现在全站顶栏（搜索、AUTO、右上角时钟）和音乐页的“唱片 / 歌词 / 歌单”分段条在同一高度，时钟压在分段条右侧（红框）。提案：分段条下移到顶栏下方 12px，歌词段同样用水线版式。
