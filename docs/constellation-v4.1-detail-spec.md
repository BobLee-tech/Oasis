## 1. 石（昼）

![石与星样张](img/spec-glyphs.webp)

### 1.1 尺寸：五档，逐档 ×1.26

| 星等 | 篇幅 | 石半径 R | 石高 H（影长） | 石形 | 星核半径 |
|---|---|---|---|---|---|
| 一等 | < 7 分钟 | 4.4px | 0.8px | 平石 | 1.6px |
| 二等 | ≥ 7 | 5.6px | 1.4px | 平石 | 2.0px |
| 三等 | ≥ 12 | 7.0px | 2.2px | 低立石 | 2.5px |
| 四等 | ≥ 18 | 8.9px | 3.2px | 立石 | 3.2px |
| 五等 | ≥ 25 | 11.2px | 4.2px | 立石 | 4.0px |

- **为什么是 ×1.26。** 人对圆面积大小的判断，大约是实际面积的 0.87 次方（Flannery 对比例符号的感知实验），所以面积翻倍，看上去并不到两倍。半径逐档 ×1.26（面积 ×1.59），补偿以后，五档在感知上大致是等距的。最大和最小的面积差约 6.5 倍：拉得足够开，又不至于让一等石变成看不见的碎屑。
- **星等门限不变，仍然是 7 / 12 / 18 / 25 分钟。** 这组门限是贴着真实数据定的。线上最长的一篇是 25 分钟，门限再高，五等就永远不会出现。
- **「高」是第二个通道，冗余编码同一件事。** 长文的石更高、影子更长，所以即使两块石半径接近，也能一眼分出轻重。这就是可视化里常说的冗余编码（redundant encoding）。
- **命中区。** 半径 + 10px，至少 18px；触屏上至少 22px（直径 44px，Apple HIG 的最小触控尺寸）。

### 1.2 形：五行石里取俯视可辨的三种

日本庭园把庭石分成五种基本形，称为「五行石」：高立、低立、平、斜出（枝形）、横卧（寄脚）。各家对这几种石的汉字名与形状的对应说法不一，本文只用描述性的叫法。俯视时，能分辨的只有扁、圆厚、高三类，所以取其中三种：

> 本文与原型只用平石 / 低立石 / 立石这类描述性名字，不引用有争议的汉字石名。

| 石形 | 用于 | 俯视扁度 `sq` | 二阶起伏 `e1` | 三阶起伏 `e2` | 皴笔 |
|---|---|---|---|---|---|
| 平石 | 一、二等 | .62 / .68 | .05 / .06 | .03 / .04 | 无 |
| 低立石 | 三等 | .80 | .08 | .05 | 一笔 |
| 立石 | 四、五等 | .88 / .92 | .10 / .12 | .06 / .07 | 两笔 |

- **轮廓。** 取 14 个点：`r(t) = R · (1 + e1·sin(2t + a1) + e2·sin(3t + a2))`，纵向乘 `sq`，旋转 `rot` 后用二次曲线过中点平滑连接。`a1`、`a2`、`e1`、`e2` 的具体值都用文章 id 做种子，所以同一篇文章永远是同一块石。
- **朝向。** 小径上的石，长轴顺着小径摆（飞石的规矩：石的长边与步行方向一致）；散石的朝向由种子决定。朝向在落座时算定，存进数据层的 `rot`，之后不再变。

### 1.3 光：四层，光源在左上 135°

| 层 | 画法 | 数值 |
|---|---|---|
| **影** | 椭圆，径向渐变 `#1E293B` 由 .22 → .10 → 0 | 偏移 `(0.75H, 0.95H)`，大小 `1.08R × 1.06R·sq`，随石一起旋转。**不跟着悬停抬起**（见 1.6） |
| **体** | 线性渐变（左上 → 右下），三个停点 | 0% 白練兑 42%；52% 石的本色；100% 鈍色兑 58%。描边 `rgba(71,85,105,.26)` 0.6px |
| **高光** | 左上一小片椭圆 | `rx .34R`，`ry .18R·sq + .4`，旋转 −28°，白練，不透明度 .55 |
| **皴** | 一两笔短弧，模仿斧劈皴 | 利休鼠 `#707C74`，0.75px，圆头，.42；只画在三等以上的石上 |

- ⚠️ **渐变停点的颜色只能写在 CSS 里。** `stop-color: color-mix(...)` 写进 class 才生效；写成 SVG 属性会静默失效，变成黑色。这正是星野文件头记下的那个坑。每个分类一支渐变（`#st-note` 等），`--c` 写在渐变元素上，由停点继承。
- **不用 `filter: blur` 做阴影。** 影子用径向渐变画，零滤镜，缩放时也不会重新栅格化。

### 1.4 石色：分类色兑进銀鼠，就是一种庭石

```
石本色 = color-mix(in oklab, 分类色 20%, 石基色)
石基色 = color-mix(in oklab, 白鼠 #BDC0BA 52%, 銀鼠 #91989F)
```

| 分类 | AURA | 得到的石 | 像什么 |
|---|---|---|---|
| 随笔 | `#39C5BB` 初音绿 | 青磁 | 带青绿的灰石 |
| 周报 | `#FFB7C5` 樱粉 | 桜鼠 | 带粉的灰石（京都鞍马石一类的暖锈色，压淡） |
| 学习笔记 | `#60A5FA` 天蓝 | 青石 | 伊予青石一类的蓝灰片岩 |
| 成长 | `#A7F3D0` 薄荷 | 苔石 | 带苔意的绿灰 |
| 项目复盘 | `#A78BFA` 藤紫 | 藤鼠 | 带紫的灰石 |

- **为什么只兑 20%。** 石头在庭园里本来就是低饱和的，分类色只是一层「矿物感」。颜色的主要承载者是庭名方块、目录栏和夜里的星晕。兑到 30% 以上，石头会开始像糖果。
- **自定义分类不需要额外设计。** 任何用户自选的颜色，经过同一个公式，自然得到一种石。

### 1.5 生长度：种子、生长中、常青

| 生长度 | 石 | 星 | 理由 |
|---|---|---|---|
| 种子 | 空心卵石：白練兑 26% 的淡底，加分类色兑 30% 的**虚线**轮廓（2 / 1.6），**没有影子**（还没扎根） | 半透明的核，外加一圈虚线环 | 两种状态都读作「还没长成」。昼夜同一套语义：空心、虚线 |
| 生长中 | 实石 | 亮星 | — |
| 常青 | 实石，**左上覆一块苔**（苔绿 `#869457`，加 3–4 粒深色苔点 `#5F6B3A`） | 四角芒（内半径 .15，边长为核的 3.3 倍） | **苔与分类色无关。** 苔就是「长久」本身；如果染成分类色，蓝苔、紫苔会让人误读 |

### 1.6 交互态

| 状态 | 表现 | 时长 / 曲线 |
|---|---|---|
| 悬停 | 石抬起：`translate(-.6px, -1.2px) scale(1.08)`；影子**留在原地**，只外扩 10% | 120ms，ease-out |
| 选中 | 初音绿圆环（用下文的强调·环色 `#2A9D95`，1.3px，半径 R+5），**沿周长画出来** | 320ms，ease-out |
| 选中 · 水纹 | 两圈：先绿后粉，相隔 180ms，从 0.6 倍放大到 5.5 倍，同时淡出 | 1500ms，BLOOM_EASE |
| 变暗 | 不透明度 .24（夜里 .20） | 480ms |
| 待照料（仅园丁可见） | 樱粉虚线圈（2 / 3），半径 R+4 | 320ms 淡入 |
| 新近照料（三周内） | 樱粉水纹，5 秒荡一圈，放大到 3.4 倍 | 相位按种子错开，避免所有石同时呼吸 |

## 2. 星（夜）

### 2.1 五层

| 层 | 画法 | 数值 |
|---|---|---|
| **晕** | 径向渐变，分类色 .42 → .12（35%）→ 0 | 半径 = 核 × 4.4。**色相只在晕上**：亮星的核在照片里本就过曝成白色 |
| **辉** | 径向渐变，白色 .62 → 0 | 半径 = 核 × 2。三等以上的星会闪烁：不透明度在 .45 和 .95 之间往返，周期 3.2–6.0 秒，相位按种子错开 |
| **核** | 实心圆 | `color-mix(in oklab, 分类色 16%, #fff)` |
| **十字星芒** | 两条细线 | 只有五等星有：长 ±7 倍核半径，白色 .2，0.6px。在视觉上对应「最亮」 |
| **四角芒** | 四角星 | 只有常青有，对应白天的苔。与十字星芒可以叠加（五等常青 = 最亮的星） |

种子星：核的不透明度 .5，无晕，外加一圈虚线环（半径为核 + 2.2，虚线 1.2 / 1.8，`rgba(226,232,240,.38)`）。

### 2.2 石与星之间的换装

同一个节点里同时画着石和星，由令牌 `--stone-o` 和 `--star-o` 切换显隐。星从 0.55 倍放大到 1 倍，带波次延迟 `--wd`（见 6.2⑤），夜幕就像从月亮那边一路亮过来。**几何不动，一个像素都不动。**

### 2.3 池面倒影：悉尼当晚的真实星空

- **数据。** Yale Bright Star Catalog 第 5 版。用的是 GitHub 上 brettonw 以 MIT 许可转换的 JSON，原始星表由 Harvard CfA 分发。取视星等 ≤ 5.0 的 1630 颗，每颗存四个整数：赤经、赤纬、星等、色温。原始 JSON 25KB，gzip 后约 10KB，已存为 [assets/bsc5-v50.json](assets/bsc5-v50.json)。
- **投影。**
  1. 按 `NOW` 算格林尼治恒星时，加上经度 151.21° 得到地方恒星时。
  2. 纬度取 −33.87°（悉尼），换算出每颗星的地平坐标：高度角和方位角。
  3. 以天顶为中心做球极投影：`ρ = tan((90° − 高度角) / 2)`。地平线在屏幕对角线的 0.56 倍处。
  4. **东西镜像**：这是池面里的倒影，不是抬头看到的天。
- **层级不许倒挂。**
  - 倒影星的半径 `clamp(.28·(5.3 − V), .35, 1.4)`px，**永远小于最暗的数据星核（1.6px）**；不透明度 ≤ .55。
  - 颜色按色温分五档（3000K 暖黄到 15000K 冷蓝），而且都往白色偏。
  - 倒影星不参与拾取，只在夜里出现（淡入 900ms，比换装晚 260ms）。
- **为什么值得做。** 前三轮的规矩是「不撒假星」。这次不是假星，而是真实的天空：今晚在悉尼抬头，南十字座就在那里。材质和数据分开，而材质本身也有出处。

### 2.4 月相

月相按朔望月 29.530589 天计算，参考朔日是 2026-01-18 19:52 UTC。亮面由半个圆盘加一段椭圆明暗界线拼成，上弦朝右、下弦朝左。旁边注「94% · 今夜月相」。月亮只在夜里出现，窄屏上不画。

## 3. 小径、灯笼、桥、砂纹

### 3.1 飞石：千鳥打ち

- **排法**：飞石的经典打法之一，踏石左右交错，像千鸟的脚印。
- **踏石**：每块半径 2.9 × 1.95px，**间距 13px**，左右交错 ±1.8px，长轴顺着小径方向，每块再随机偏转 ±8°。
- **颜色**：底色 `#D6D2C8`，描边 `rgba(101,103,101,.28)` 0.7px，影子偏移 (.6, .8)，影子色 `rgba(30,41,59,.1)`。
- **避让**：两端各让出「石半径 + 8px」，踏石不压在石上。
- **踏石数随缩放重排**，保证在屏幕上始终是 13px 一步：拉近时步子不会被放大成大饼。
- **点亮**：点亮的小径，踏石兑 34% 初音绿。
- **夜里**：换成 1px 的星座连线，`rgba(226,232,240,.5)`，点亮时升到 .92。

### 3.2 石灯笼：小径入口 = 第一章

- **字形**：春日灯籠的剪影，高 15px，自下而上依次是基礎、竿、中台、火袋（带火口）、笠、宝珠。纯矢量绘制，由本项目原创。
- **颜色**：
  - 白天：灯身 `#8E938C`，火口是白練色。
  - 夜里：灯身 `#26303F`，火口琥珀 `#FDBA74`（取自 AURA），外加一圈暖光（半径 11px，不透明度 .55 → .16 → 0）。
- **位置**：第一章那块石之前，沿小径的反方向退「石半径 + 15px」。合集名写在灯笼旁边：先试右侧，再试左侧。
- **一个符号同时承担三件事**：
  1. 标出小径从哪里开始，也就是阅读方向。
  2. 给合集名一个锚点。
  3. 呼应全站的「灯火 · Lanterns」场所。

  目录栏的合集行、星卡的小径进度条也用同一个灯笼图标。

### 3.3 桥（双链）

| | 昼 · 石桥 | 夜 · 鹊桥 |
|---|---|---|
| 画法 | 两条线叠画：底线 3.6px `rgba(100,116,139,.5)`，上面压 1.8px 底色，形成双栏杆 | 1.1px 樱粉 .62，虚线 3 / 4 |
| 形 | 二次曲线，向一侧拱 22%（拱向由种子决定） | 同左 |
| 平时 | 不透明度 .32 | 同左 |
| 聚焦 | 与焦点相连的桥升到 1，其余降到 .1 | 同左 |

### 3.4 砂纹

- **三圈**：离石边 9 / 17 / 25px（屏幕尺寸）。smooth-min 的软化系数 K = 7px。
- **每片庭单独计算。** 描边色为 `color-mix(分类色 34%, 基色)`：白天基色是石板灰，透明度 .20，最里一圈 .32；夜里基色是初音绿，透明度 .09，最里一圈 .17。
- **直纹**：间距 7px，`rgba(100,116,139,.085)`。用一个蒙版挖掉每片庭最外圈砂纹以内的区域；外缘用 55% 处开始的径向渐隐收边，**没有版框**。
- **夜里**：最外圈以内再铺一层 `rgba(102,222,213,.022)`，作为池面的微光。

### 3.5 话题圈

- 只用该话题的成员重算一次场，K = 12，取离石边 30px 的那条等值线。
- 画法：樱粉 1.2px 虚线（4 / 5），填充樱粉 12%。
- 成员之间超过 60px 时，改用最小生成树的点线（1 / 5）把它们串起来。
- 出现时淡入 320ms。

## 4. 色彩系统（实测对比度）

![色板与对比度](img/spec-color.webp)

### 4.1 规则

1. **文字 ≥ 4.5:1**（WCAG 2.2 AA，正文）。**必须被看见的图形 ≥ 3:1**（1.4.11，包括选中环、拨盘把手）。**材质不设要求**（石、砂、飞石、灯身）：它们不承载必须读出的信息，信息总有文字或第二通道兜底。
2. **分类色写成小字时一律兑墨**：白天 40% 兑 `#1E293B`，夜里 88% 兑 `#F8FAFC`。这也是全站 `.oasis-accent-ink` 的做法。
3. **初音绿拆成三种用途**：画线和大面积用 `#39C5BB`；必须被看见的图形用「强调·环」`#2A9D95`（白天 3.11:1）；小字用 `#1B7A74`（4.85:1）。

### 4.2 本轮修正（原型实测发现不达标的三处）

| 令牌 | 旧值 | 旧对比度 | 新值 | 新对比度 |
|---|---|---|---|---|
| 昼 · 次墨 `--ink2` | `#64748B`（slate-500） | 4.48 | `#5B6B80` | **5.13** |
| 昼 · 淡墨 `--ink3` | `#94A3B8`（slate-400） | 2.42 | `#7F8B9C`（**只用于装饰性小字**） | ≈ 3.2 |
| 夜 · 淡墨 `--ink3` | `#64748B` | 4.02 | `#7A8AA0` | **5.43** |
| 昼 · 成长类小字 | 45% 兑墨 | 4.28 | 40% 兑墨 | **4.89** |
| 昼 · 选中环 | `#39C5BB` | 2.00 | `#2A9D95` | **3.11** |

> 全站其他场所也大量用 slate-400 / slate-500 写小字，存在同样的问题。建议 P0 顺手把 `--ink2` / `--ink3` 提为全站令牌。

### 4.3 日本传统色（石的材质色）

### 5.2 注记规则：方向本身就是层级（Imhof）

Imhof 在 *Positioning Names on Maps*（1975）里给地名定了规矩：面状名跟着区域走，点状名贴在点的右上，线状名顺着线。本方案把这三类映射到三种排法：

| 类别 | 地图上 | 排法 |
|---|---|---|
| 面状 | 庭（分类） | **竖排木札**：顶上 7px 圆角方块（分类色）；竖排中文；右侧一列侧排英文；**篇数放在最后一个字下方 12px**（按渲染后的实际字高定位） |
| 线状 | 小径（合集） | 写在入口石灯笼旁；依次试右、左、下、上 |
| 点状 | 石（文章） | 八个方位，按右上 → 左上 → 右下 → 左下 → 上 → 下 → 右 → 左的顺序试 |

**择位的约束**（全部在屏幕空间里判断）：

1. **只能落在地图的可用区里**：页头以下（≥ 146px）；Dock 以上（离底 ≥ 108px，拨盘打开时 ≥ 196px）；目录栏右侧；星卡左侧。
2. **不压石、不压灯笼、不压已放下的注记。** 碰撞检测留 2–3px 边距。
3. **庭名要离自家的石最近。** 候选框中心最近的那块石必须属于这片庭，否则名字会被读成邻庭的。竖排的六个候选位都放不下时，退为横排再试；横排也放不下，就只接受离庭心 120px 以内的位置；仍然不行，就不写。
4. **星名的配额随缩放放宽。** 四档依次是 10 / 22 / 48 / 全部，另外加上焦点和它的邻居。庭里只有一两块石时，这一两块永远写名字：它们就是这片庭的全部目录。

## 6. 动效系统

### 6.1 令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| `--t-xs` | 120ms | 悬停、按钮、颜色变化 |
| `--t-sm` | 200ms | **退场**：卡片关闭、拨盘沉下、注记隐去 |
| `--t-md` | 320ms | 卡片进场、选中环画出、话题圈 |
| `--t-lg` | 480ms | 目录栏开合、拨盘升起、相机让位 |
| 相机 | 640ms | 飞到目标、全图 |
| `--t-xl` | 900ms | 进场的总时长上限、倒影星空淡入 |
| `--ease-out` | `cubic-bezier(.16,1,.3,1)` | **进场**。即全站的 BLOOM_EASE / customEase |
| `--ease-in` | `cubic-bezier(.4,0,.9,.2)` | **退场**。即 App.tsx 里场所退场用的曲线 |
| `--ease-io` | `cubic-bezier(.65,0,.35,1)` | 播放、昼夜换光、砂纹耙出 |

两条原则，与 Material 3 一致：

- **进场用减速曲线，退场用加速曲线。** 进来的东西要落定，出去的东西不需要被注视。
- **退场比进场短。** Material 的例子是进 225ms、出 195ms；这里是 320 / 200。

实现约束：

- 只动 `transform`、`opacity`，以及一次性的 `stroke-dashoffset`（选中环、砂纹耙出）。
- 所有时长都乘以 `--slow`。原型里按 `m` 慢放五倍；截分镜时用的是 6 倍。

### 6.2 编排

#### ① 进场（首次进入星图 / 切换数据规模）

| 时刻 | 发生什么 |
|---|---|
| 80ms | 目录栏从左滑入 16px 并淡入，480ms |
| 0 → ≤ 700ms | **石按种下的先后逐块落下**：每块 420ms，从上方 7px、0.7 倍，过冲到 1.05 倍再落定。相邻两块的间隔为 `min(55ms, 700/N)` |
| 每块落地后 140ms | 砂面荡开一圈：900ms，放大到 2.6 倍并淡出 |
| 260ms 起 | **砂纹一圈一圈被耙出来**：描边从 0 画到 1，1100ms，ease-io；每片庭晚 90ms，每一圈晚 120ms。只在桌面播放 |
| 最后一块落下 + 180ms | 小径与灯笼淡入 |
| 最后一块落下 + 380ms | 注记淡入，480ms |

![进场分镜](img/motion-enter.webp)

#### ② 选中、换星、关闭

- **选中。** 同时开始四件事：
  - 两圈水纹：绿、粉各一，粉的晚 180ms。
  - 选中环画出：320ms。
  - 相机让位：只在星被遮挡时触发，640ms。
  - 星卡进场：从右侧 12px 处淡入，320ms，ease-out；卡内七行按 40ms 错峰，各自上浮 6px。
- **换星（卡片已打开）。** 框不动，只换内容：旧内容 120ms 淡出并上移 3px（ease-in），新内容按 40ms 错峰进来。
- **关闭。** 200ms，ease-in，向右退 12px。比进场短，因为关掉的东西不需要再看。

![选中分镜](img/motion-select.webp)

#### ③ 时光拨盘（这一段请重点看）

**打开**（点「◴ 时光」）：

| 时刻 | 发生什么 |
|---|---|
| 0 | 面板从底部 14px、0.96 倍升起并淡入，480ms，ease-out。**地图同步上移让位**：取景下沿抬高 84px，也是 480ms |
| 120ms 起 | **月份柱依次长出**：`scaleY(0 → 1)`，锚点在柱底，480ms，每根晚 14ms；已发生的月份是初音绿，未来的月份是淡墨 |
| 160ms | 播放键与节气标签（例如「秋分 · 2026/9/24 · 60 石」）淡入 |
| 0 → 2400ms | 提示条「拖动或按 ▶，看花园怎样一块一块长出来」出现后自动收起 |
| 200ms | 焦点落到拨盘上：`←` / `→` 可以逐步拖动，空格播放或暂停，`Esc` 收起 |

![时光·打开](img/motion-timeopen.webp)

**拖动或播放：**

- **播放**：从当前位置播到今天。按剩余比例算时长，全程 7 秒，ease-io。播到头自动停止。
- **新生的石**：「砰」地落下（从 0.4 倍到 1.12 倍再到 1，620ms），同时荡开一圈水纹（白天樱粉、夜里初音绿，900ms）。
- **尚未种下的石**：200ms 加速淡出。
- **刷新节流**：砂纹、小径、注记、目录这些较重的重绘，最多每 140ms 刷新一次；手松开（`change` 事件）时再完整刷新一遍。
- **拨盘上的刻度**：月份柱底下是二十四节气刻度，「分至启闭」八个节气的刻度更长；年份写在元旦的位置。

**收起**（点 × 或按 `Esc`）：

| 时刻 | 发生什么 |
|---|---|
| 0 → 520ms | 如果拨盘不在「今天」，**先把花园快进回今天**：拨盘把手以 ease-out 滑到最右，途中新生的石依次落下并荡开水纹 |
| 680ms | 面板加速沉下：200ms，ease-in，下移 14px 并缩到 0.96；月份柱同时收回（200ms，不错峰） |
| 680ms | 地图取景同步回到原位，480ms |

**为什么要先快进再收起：** 如果直接收起，花园会在同一帧里凭空冒出一大片石头，看上去像出了错。先让它「长回来」，再把工具收走，用户就知道现在看到的是今天的花园。

![时光·收起](img/motion-timeclose.webp)

![拨盘打开的样子](img/after-time-60.webp)

#### ④ 悬停、目录联动、话题圈、搜索

- **悬停石**：抬起，120ms；它的小径和邻居亮起，其余降到 .24（480ms）；目录里对应的行高亮，必要时滚动到可见处。
- **悬停目录行**：地图上对应的石、小径或整片庭亮起，其余变暗。**悬停不移动相机**，点击才飞过去。
- **话题圈**：淡入 320ms；移开时立刻清除。
- **搜索**：不匹配的石降到 .24，匹配的石名字全部浮出。

#### ⑤ 昼夜切换：三拍

| 拍 | 时刻 | 发生什么 |
|---|---|---|
| 一 · 收 | 0 → 160ms | 注记淡出（ease-in）。**字色和描边如果跟着底色一起渐变，过程中段会糊成一团灰**，所以先把字收起来 |
| 二 · 换光 | 160ms 起 | 切换主题令牌；**光从月亮所在的右上角一路换过去**：每个节点按 `(视口宽 − x) + y` 归一化，最多延迟 520ms；石淡出 520ms，星淡入并从 0.55 倍放大，620ms；倒影星空晚 260ms，淡入 900ms；副标题换句 |
| 三 · 放 | 760ms 起 | 注记重新淡入，320ms，ease-out |

![昼夜分镜](img/motion-theme.webp)

> 附带发现：全站的日夜切换是整屏背景色做 1500ms 的线性过渡，中段必然经过一片泥灰（`#FAF8F3` 与 `#0A0F1D` 的中点约是 `#827F88`）。星图用「先收字、再按波次换光」把这段中间态藏了起来。其他场所如果也觉得换装发闷，可以借用同样的「收 → 换 → 放」节奏。

### 6.3 性能与降级

| 项 | 规则 |
|---|---|
| 持续动画 | 只有三种：新近照料的水纹、星的闪烁、落叶/萤火。全部只动 transform 和 opacity，页面隐藏时暂停 |
| 一次性描边动画 | 选中环、砂纹耙出。砂纹耙出只在桌面、只在进场时播放 |
| `prefers-reduced-motion` | 所有动画和过渡压到 0.01ms，错峰归零：进场直接呈现最终态，相机瞬移，拨盘播放直接跳到终点，昼夜直接切换。闪烁和水纹不播 |
| 触屏（`pointer: coarse`） | 不播砂纹耙出，不显示悬停抬起；命中区至少 22px |

### 8.4 时光拨盘的状态机

```
closed ──open──▶ opening(480) ──▶ open.idle ◀──────────────┐
                                     │  drag / ←→ ──▶ open.scrubbing ─(change)─┘
                                     │  ▶ / Space ──▶ open.playing ─(到今天 | 暂停)─┘
                                     └─ × / Esc ──▶ closing.fastForward(520, 仅当不在今天)
                                                      ──▶ closing.sink(200) ──▶ closed
```

- **cutoff 放在 React state 里，由 TimeDial 持有。**
  - 石的 `future` / `born` 用 class 切换，在 SkyStage 的 effect 里直接写 DOM。
  - 砂纹、注记这些重绘走 140ms 节流。
- **收起时一定要先回到今天**，再关面板，避免「一帧冒出一片石头」。

### 8.5 数据层

- `layoutStars()` 增加两样：
  1. **庭址**：黄金角 + 0.74 rad；半径 `270·√k`；纵向压到 0.66。
  2. **石的朝向 `rot`**：小径上的石取前后两块石的连线方向，散石由种子决定。
- 前缀不变量不受影响：`rot` 只依赖前后两块石，而这两块在落座时已经确定。
- **石灯笼的位置不存。** 它由「第一章 + 缩放」即时算出。
- 实测（原型，Chromium）：160 篇布局 36ms、砂纹 64ms；300 篇布局 73ms、砂纹 114ms。按庭缓存砂纹，并挪进 Worker 以后，**主线程每次阻塞 < 50ms**。这是 P2 的判据。
